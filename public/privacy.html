MindSwipe Privacy Policy

Last updated: August 16, 2026

Pre-release draft. Publisher identity, monitored support email, and permanent policy URL must be completed before store publication.

Overview

MindSwipe currently works without accounts, a remote user database, analytics, advertising, payments, cloud sync, or location access.

Information stored on your device

MindSwipe stores interests, preferences, completed/recent/saved card IDs, saved places, XP, streaks, session progress, local trips, and trip notes in local browser/app storage. A migration or corrupt-record backup may also be retained locally so upgrades do not casually destroy progress.

Notifications

If you enable reminders, MindSwipe schedules notifications locally. Android may request notification permission. Exact delivery is optional and opens Android's Alarms and reminders setting only after you select that mode.

Location

The current version does not request or use precise, approximate, foreground, or background location. You choose destinations manually.

External links

When you choose to open a source, image-license page, Google Maps, Waze, privacy page, or support page, that external service receives the normal request and any encoded place/directions parameters needed for the handoff. MindSwipe does not send your local progress or trip notes with those links.

Sharing and sale

The current version does not sell personal data or share local progress with advertisers, analytics providers, or a MindSwipe backend.

Removing local data

Use the in-app reset, clear site/app storage, or uninstall. The current version has no server copy to delete. Android cloud backup is disabled.

Future changes

Accounts, analytics, ads, payments, AI services, crash reporting, cloud sync, remote packs, or location would require an updated policy and store review before release.

Contact

A monitored support email is required before publication. Pre-release project issues can use GitHub Issues, but never post personal or sensitive information publicly.
